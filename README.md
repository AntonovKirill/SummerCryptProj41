# SummerCrypProj41 — MQS Solver

Проект предназначен для исследования и решения систем полиномиальных уравнений над конечными полями (MQS — Multivariate Quadratic Systems) с использованием линеаризующих множеств, деревоподобного поиска и различных эвристик.

---

## 🏗 Архитектура проекта

### Основные модули

- **`main.cpp`** — точка входа в программу. Отвечает за парсинг параметров командной строки, конфигурацию запуска и вызов соответствующего алгоритма решения.
- **`equations_system.cpp / .hpp`** — формат хранения системы MQS. Раздельно описывает списки квадратичных и линейных уравнений, а также содержит логику чтения MQS из файлов.
- **`linearizing_set.cpp / .hpp`** — описание логики применения линеаризующих множеств для упрощения и преобразования системы.
- **`linear_system.cpp / .hpp`** — методы и алгоритмы для решения систем линейных уравнений.
- **`quadratic_system.cpp / .hpp`** — методы и алгоритмы для анализа и решения квадратичных уравнений.
- **`search_tree.cpp / .hpp`** — логика решения MQS методом обхода дерева вывода. Включает:
  - Эвристики выбора переменных/уравнений
  - Поиск с возвратом (_Backtracking_) и _Backjumping_
  - Конфликтные ограничения
  - Правила вывода (_Inference rules_)

### Вспомогательные файлы и папки

- **`encodings/*.mqs`** — папка с тестовыми файлами и экземплярами кодировок MQS.
- **`implication_graph.cpp / .hpp`** _(опционально)_ — графы импликаций для распространения литералов.
- **`disjoint_set_union.cpp / .hpp`** _(опционально)_ — структура данных «Система непересекающихся множеств» для эквивалентности литералов.
- **`test.cpp`** _(опционально)_ — набор модульных и интеграционных тестов.
